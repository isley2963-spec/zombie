Desktops

Three desktops, one login screen

All three are installed. You choose one at sign-in and run one at a time, which is how Zombie OS stays inside 1 GB.

GNOME

A clean, touch-friendly desktop with an Activities overview and almost nothing to configure. It is the most polished of the three and the heaviest.

Zombie OS sets it to the dark style by default and removes the file indexer, the software center and the welcome tour to save memory.

Hyprland

A tiling Wayland compositor driven from the keyboard. It uses the least memory, so it is the best fit for a 1 GB machine.

Zombie OS ships a ready config with blurred glass windows, a translucent Waybar, a launcher, notifications and a lock screen. Animations are off to save GPU and RAM.

Memory

1GB RAM

Tuned to fit a small machine

Zombie OS keeps the stock Fedora kernel and trims everything around it.

  • Compressed swap in RAMzram with zstd gives you roughly double the working room before the disk is touched.
  • earlyoom on guardKills a runaway app before the system freezes, and never touches your desktop shell.
  • Fewer background servicesNo file indexer, software center, printing service, crash reporter or Bluetooth stack running by default.
  • A small journalLogs live in memory and are capped at 24 MB.

Live USB vs. installed. The live ISO runs from memory and needs more than 1 GB to be pleasant. Install it to disk for the 1 GB experience, and pick Hyprland if memory is tight.

Get it

Build your own ISO

There is no prebuilt download yet. You build the ISO yourself on any Fedora machine with internet access and about 25 GB free. The size depends on the build, so it is not a fixed number.

1. Unpack the project

unzip zombie-os-fedora.zip
cd zombie-os-fedora

2. Build

This validates the kickstart, downloads the packages and produces the ISO and a checksum in out/.

sudo ./build.sh

3. Write it to a USB stick

Replace /dev/sdX with your USB stick. This erases it.

sha256sum -c out/zombie-os-*.iso.sha256
sudo dd if=out/zombie-os-*.iso of=/dev/sdX bs=4M status=progress oflag=sync

4. Boot, pick a desktop, install

Boot from the stick, run the installer from the live session, and choose GNOME, Plasma or Hyprland at the login screen.

Questions

Before you build

Can all three desktops run at once?

No. All three are installed and you pick one at the login screen. Running them together would not fit in 1 GB.

Why Fedora and not Red Hat Enterprise Linux?

Fedora is free to use and redistribute, it is current, and it packages the desktops Zombie OS needs. RHEL requires a subscription and is aimed at servers.

How big is the ISO?

Several GB, because it carries three desktops. The size comes from what is inside and cannot be set to an exact number. To make it smaller, remove the packages for a desktop you do not want from zombie-os.ks and rebuild.

Is it a new kernel?

No. Zombie OS uses the standard Linux kernel from Fedora, so hardware support and security updates come straight from upstream Fedora.

Does Hyprland work on any machine?

It needs a working GPU driver. It runs on most real hardware and in virtual machines with 3D acceleration enabled. If it will not start, use Plasma or GNOME.

Is there a prebuilt download?

Not yet. Building it yourself takes one command, and you can read every package and setting in the kickstart first.
